# Guitar Hero Demo

This repository is a blank Unity starter for a custom rhythm game inspired by Guitar Hero.

## What is included
- Unity project structure for a rhythm game
- C# scripts for note spawning, scoring, and input
- Basic project setup and Git ignore rules

## How to open in Unity
1. Install Unity Hub and Unity 2022 LTS or newer.
2. Open the repository folder as a Unity project.
3. Create a Scene named `Main` if Unity prompts.
4. Attach `RhythmGameManager` to an empty GameObject and assign a `NoteSpawner`.
5. Add a 4-lane note highway and use the keyboard controls:
   - A / S / D / F for lanes 1–4
   - Space to start

## Controls
- Press the lane buttons on the beat to hit notes.
- Get combo streaks for better score.
- Missed notes decrease health and combo.
